# Miguel Cayllahua — Portfolio

Página personal de **Miguel Cayllahua Quispe**, Ingeniero de Confiabilidad & Monitoreo de Condición (CBM).

Sitio estático (HTML/CSS/JS puro, sin dependencias de build) pensado para GitHub Pages.

## Contenido
- Resumen profesional y áreas clave de experiencia (CBM, confiabilidad estadística, ML aplicado a mantenimiento).
- Trayectoria laboral (timeline animado).
- Proyecto insignia: [RELIABILIT-IA](https://angel19968.github.io/reliabilit-ia/).
- Educación, certificaciones y habilidades técnicas.
- Contacto (WhatsApp, correo, LinkedIn) y descarga de CV.

## Desarrollo local
Abre `index.html` directamente en el navegador, o sirve la carpeta con cualquier servidor estático:

```bash
npx serve .
```

## Publicación (GitHub Pages)
1. Push a la rama `main` de este repositorio.
2. En **Settings → Pages**, selecciona la rama `main` y carpeta `/ (root)`.
3. El sitio queda disponible en `https://<usuario>.github.io/<repo>/`.
